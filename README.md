# 画像結合ツール

複数の画像をグリッド状に1枚へ結合する、HTML 1ファイルで動くツールです。
`index.html` をブラウザで開くだけで使えます（インストール・通信なし）。

Web版: https://watson-jp.github.io/tool-gazou-ketsugou/

## 使い方

1. 画像をファイル選択するか、ドロップエリアにドラッグ＆ドロップ
2. プレビューのサムネイルをドラッグして結合順を並び替え
3. 列数と「サイズ違いの画像」の扱いを選んで「結合」
4. 「保存」で PNG としてダウンロード

## サイズ違いの画像の扱い

セルの大きさは1枚目の画像に合わせます。

- **比率を保って収める**: 画像全体が入るよう縮小し、余白は透明
- **比率を保って切り抜く**: セルを埋めるよう拡大し、はみ出しをカット
- **引き伸ばす**: セルにぴったり合わせる（比率が変わる）
